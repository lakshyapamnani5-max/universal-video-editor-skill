# Creating and combining styles

1. Create `styles/<style-id>/`.
2. Add `STYLE.md` describing visual rules, typography, colour, pacing, transitions, caption placement and accessibility.
3. Add `style.json` with machine-readable defaults.
4. Add an example edit plan and rendered sample if possible.
5. Add the style to `styles/index.json`.
6. Test the style on landscape, portrait and square footage.

Hybrid styles:
- First style is the base.
- Second style contributes one or two accents (e.g. typography or pacing).
- Never combine two incompatible font systems or competing colour palettes.
- Keep subtitles readable and inside safe areas.
